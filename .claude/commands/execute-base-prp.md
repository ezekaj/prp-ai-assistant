# Execute Base PRP

Execute a Product Requirements Proposal (PRP) file with systematic validation.

## Execution Process:

### 1. Load PRP
- Read and understand the PRP file completely
- Gather all referenced context and documentation
- Extend research if any gaps are identified

### 2. ULTRATHINK
- Create comprehensive implementation plan
- Break down into discrete, ordered tasks
- Use TodoWrite tool to track progress
- Identify implementation patterns from codebase

### 3. Execute
- Implement the code following the PRP blueprint
- Reference existing patterns and files as specified
- Follow the ordered task list from the PRP

### 4. Validate
- Run all validation commands specified in PRP
- Fix any failures using error patterns
- Re-run validation until all tests pass

### 5. Complete
- Ensure all PRP checklist items are completed
- Run final validation suite
- Report completion status and any deviations
- Verify full PRP implementation requirements met

### 6. Reference
- Keep PRP available for reference during implementation
- Update PRP if implementation reveals new requirements

## Error Handling:
- If validation fails, analyze error patterns
- Apply fixes and retry validation
- Document any PRP assumptions that proved incorrect

## Success Criteria:
- All validation commands pass
- All PRP checklist items completed
- Feature works as specified in requirements
