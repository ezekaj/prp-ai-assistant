# PRP Master Command

The ultimate PRP command that orchestrates everything.

## Master Capabilities:

### 🧠 Intelligent Analysis
- **Deep Codebase Scan**: Analyze entire codebase for patterns, dependencies, and architecture
- **Performance Profiling**: Identify performance bottlenecks and optimization opportunities  
- **Security Assessment**: Scan for security vulnerabilities and compliance issues
- **Technical Debt Analysis**: Identify and quantify technical debt

### 🚀 Autonomous Implementation
- **Multi-Phase Execution**: Break complex features into manageable phases
- **Parallel Processing**: Execute independent tasks simultaneously
- **Real-Time Validation**: Validate each step with immediate feedback
- **Adaptive Problem Solving**: Automatically adjust approach based on encountered issues

### 📊 Advanced Analytics
- **Success Prediction**: Predict implementation success probability
- **Resource Estimation**: Accurate time and resource requirement predictions
- **Risk Assessment**: Identify and quantify implementation risks
- **Impact Analysis**: Understand full system impact of changes

### 🔄 Continuous Learning
- **Pattern Recognition**: Learn from successful and failed implementations
- **Optimization Suggestions**: Suggest improvements based on historical data
- **Best Practice Evolution**: Evolve best practices based on team patterns
- **Knowledge Retention**: Remember and apply lessons learned

### 🛡️ Quality Assurance
- **Multi-Layer Testing**: Unit, integration, e2e, performance, security testing
- **Code Quality Enforcement**: Automated linting, formatting, complexity analysis
- **Documentation Generation**: Auto-generate comprehensive documentation
- **Compliance Checking**: Ensure adherence to coding standards and regulations

## Usage Modes:

### Quick Mode
```
/prp-master quick {feature-description}
```
- Rapid PRP generation and implementation
- Suitable for simple features
- Minimal user interaction required

### Deep Mode  
```
/prp-master deep {feature-description}
```
- Comprehensive analysis and planning
- Detailed risk assessment
- Multiple implementation approaches
- Extensive validation

### Learning Mode
```
/prp-master learn {completed-feature}
```
- Analyze completed implementation
- Extract patterns and lessons
- Update knowledge base
- Improve future predictions

### Analytics Mode
```
/prp-master analytics
```
- Generate comprehensive dashboard
- Identify improvement opportunities
- Track team performance metrics
- Export insights and reports
